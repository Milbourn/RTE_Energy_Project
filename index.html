Data Extraction RTE France APIs, Python, OAuth2 token authentication
1.1

RTE France API access

RTE (Réseau de Transport d'Électricité) publishes open APIs covering real-time and historical grid data. Four separate API applications were registered to pull distinct datasets, each using secure token-based authentication that automatically refreshes credentials on every run.

Secure token auth 30-min granularity 30-day window chunks Rate-limit handling
1.2

Four datasets extracted

⚡
Actual Generation — generation by production type (nuclear, gas, wind, solar, hydro, biomass) at 30-min intervals. 417K rows after backfill.
📈
Consumption — national electricity consumption with realised and forecast values. 464K rows. Used to calculate generation surplus and peak demand hour.
🌍
Physical Cross-Border Flows — import/export volumes with 8 neighbour countries: Spain, Germany, Belgium, Switzerland, Italy, Luxembourg, UK, Ireland. 1.44M rows.
💶
Wholesale Prices — day-ahead market clearing prices (€/MWh) via ENTSO-E transparency platform, joined to daily generation aggregates for merit-order analysis.

Schema and table structure

Raw data lands in Snowflake in four staging tables, one per API source. The pipeline is designed so it can safely run multiple times without duplicating data — if the daily scheduler fires twice, existing rows are updated rather than duplicated.

Model architecture

Two layers. Staging models clean and standardise the raw tables — casting types, renaming columns, filtering to realised values. Mart models pivot and aggregate to daily granularity, joining generation, consumption, and price into the three tables Power BI connects to directly.

🔷
Staging layer — stg_actual_generation, stg_consumption, stg_physical_flows, stg_wholesale_prices
🔶
Mart layer — fct_energy_hourly (wide pivoted fact), mart_generation_daily, mart_cross_border_flows. Output schema: DBT_NMILBOURN

What the data shows

When renewables surge, does the wholesale price actually fall?
Yes. Pearson r = -0.62 between daily renewables share and day-ahead price across 1,392 days. Each 10pp rise in renewable penetration displaces gas at the margin and pulls the clearing price down — the merit-order effect, visible in the data without any modelling assumptions.
What is France's generation profile?
Average output of 55.9 GW, with nuclear providing 68%. France runs a structural surplus of around 1.5 GW on average and is a consistent net exporter to neighbours including Germany, Belgium, and Italy.
When is demand highest?
Peak consumption is at 19:00, with a secondary morning peak around 09:00. Summer demand dips as heating load disappears, while winter evenings see the highest stress on the grid.

Tech Stack Full layer-by-layer breakdown
LayerTool / ServiceRole in this project
Source RTE France Open API Four endpoints covering generation, consumption, cross-border flows, and wholesale prices. Data at 30-min intervals with secure token authentication.
Extraction Python 3.11 Pulls data from the APIs, normalises it, and loads it into Snowflake. Runs automatically each day via Windows Task Scheduler.
Storage Snowflake (Azure UK South) Cloud data warehouse storing all raw and transformed tables. Designed so the daily load can safely rerun without creating duplicates.
Transform dbt Cloud 7 SQL models that clean, reshape, and aggregate the raw data into analysis-ready tables. Connected to GitHub for version control, runs on a daily schedule.
Version control GitHub Full project history for all dbt models, SQL tests, and source definitions.
Visualisation Power BI Desktop + Service Live connection to Snowflake mart tables, 40+ calculated measures, custom HTML KPI cards with sparklines, published as a public Power BI App.
