01
Data Extraction Four RTE France APIs, Python, OAuth2 token authentication
1.1

RTE France API access

RTE (Réseau de Transport d'Électricité) exposes several public APIs covering real-time and historical grid data. I registered four separate applications to pull distinct datasets: actual generation by production type, consumption, physical cross-border flows, and wholesale market prices via ENTSO-E. Each uses OAuth2 client credentials with a Base64-encoded key pair.

1.2

Python ETL — backfill and incremental load

The ETL script handles both a full historical backfill (chunked into 30-day windows to respect API rate limits) and incremental daily loads via Windows Task Scheduler. Data is written to Snowflake using the snowflake-connector-python library with upsert logic to prevent duplicates on reruns.

rte_etl.py — token auth + paginated extract
def get_token(api_key: str) -> str:
    """Exchange Base64 key for Bearer token."""
    resp = requests.post(
        "https://digital.iservices.rte-france.com/token/oauth/",
        headers={"Authorization": f"Basic {api_key}",
                 "Content-Type": "application/x-www-form-urlencoded"},
        data={"grant_type": "client_credentials"}
    )
    return resp.json()["access_token"]

def fetch_generation(token: str, start: str, end: str):
    """Pull actual generation by production type."""
    url = ("https://digital.iservices.rte-france.com"
           "/open_api/actual_generation/v1/actual_generations_per_unit")
    headers = {"Authorization": f"Bearer {token}"}
    params  = {"start_date": start, "end_date": end}
    return requests.get(url, headers=headers, params=params).json()

Snowflake Raw Layer Staging schema, table design, upsert pattern
2.1

Schema and table structure

Raw data lands in the GENERATION schema inside the RTE_ENERGY database. Four staging tables mirror the four API sources. The Python connector writes each batch using MERGE INTO to handle reruns safely — no duplicate rows even if the scheduler fires twice.

Snowflake — raw table structure
-- Raw generation table (simplified)
CREATE OR REPLACE TABLE RTE_ENERGY.GENERATION.ACTUAL_GENERATION (
    PERIOD_START     TIMESTAMP_NTZ,
    PERIOD_END       TIMESTAMP_NTZ,
    PRODUCTION_TYPE  VARCHAR(50),
    VALUE_MW         FLOAT,
    UNIT_NAME        VARCHAR(100),
    LOADED_AT        TIMESTAMP_NTZ DEFAULT CURRENT_TIMESTAMP
);

-- Upsert pattern used by Python ETL
MERGE INTO ACTUAL_GENERATION t
USING staging_batch s
  ON t.PERIOD_START = s.PERIOD_START
  AND t.PRODUCTION_TYPE = s.PRODUCTION_TYPE
WHEN MATCHED THEN UPDATE SET t.VALUE_MW = s.VALUE_MW
WHEN NOT MATCHED THEN INSERT VALUES (s.*);

dbt Cloud Transformation Staging + mart layers, 7 models, GitHub-connected
3.1

Model architecture

Models are split across two layers. Staging models clean and standardise the raw tables — casting types, renaming columns, filtering bad rows. Mart models aggregate to daily granularity and join datasets together, producing the three tables that Power BI connects to directly.

dbt — mart_generation_daily.sql (simplified)
WITH hourly AS (
    SELECT
        DATE_TRUNC('day', period_start) AS date_day,
        AVG(nuclear_mw)             AS avg_nuclear_mw,
        AVG(total_generation_mw)    AS avg_total_mw,
        AVG(renewables_pct)         AS avg_renewables_pct,
        AVG(price_eur_mwh)          AS avg_price_eur_mwh
    FROM {{ ref('stg_actual_generation') }}
    GROUP BY 1
)
SELECT *,
    -- merit-order bucket for bar chart
    CASE
        WHEN avg_renewables_pct < 10 THEN '0–10%'
        WHEN avg_renewables_pct < 20 THEN '10–20%'
        WHEN avg_renewables_pct < 30 THEN '20–30%'
        ELSE '30%+'
    END AS renewables_bucket
FROM hourly

4.2

Key findings

When renewables surge, does the wholesale price actually fall?
Yes. Pearson r = -0.62 between daily renewables share and day-ahead price across 1,392 days. Each 10pp rise in renewable penetration displaces gas at the margin and pulls the clearing price down — the merit-order effect, visible in the data without any modelling assumptions.
What is France's generation profile?
Average output of 55.9 GW, with nuclear providing 68% of generation. France runs a structural surplus of around 1.5 GW on average and is a consistent net exporter.
When is demand highest?
Peak consumption hour is 19:00, with a secondary morning peak around 09:00. Summer demand dips markedly as heating load disappears, while winter evenings see the highest stress on the grid.
