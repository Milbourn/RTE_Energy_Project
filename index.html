Mapping France's Electricity Mix

End-to-end data engineering project · Jan 2022 to present · Live dashboard, updated daily
Python Snowflake dbt Power BI RTE France API Claude Code

Overview

France runs the most nuclear-heavy grid in the world, exports its surplus to half of Europe, and watched wholesale prices collapse from €281 to €60 per MWh in two years. This project tracks all of it: four RTE France APIs feeding 3 million rows through Python, Snowflake, and dbt into a live Power BI dashboard.

I built it to answer a question I kept running into: when renewable generation surges, does the wholesale price actually fall? The answer turned out to be more interesting than a yes or no, because the data spans the 2022 energy crisis and the recovery that followed.

What the data shows

In 2022, France pulled dozens of nuclear reactors offline for emergency corrosion inspections. Generation dropped to 49 GW, wholesale prices averaged €281/MWh, and the most reliable grid in Europe suddenly wasn't. The dataset captures the full arc from crisis to recovery:

Does renewable supply push prices down?

In a stable market, clearly yes. The year-on-year correlation between daily renewables share and day-ahead price settles around r = −0.66 once the crisis passes. But during 2022 itself the relationship nearly vanished (−0.23): gas-price shocks swamped everything else. The merit-order effect is real, but it only becomes the dominant price driver once the wider market calms.

Who buys France's recovered output?

Germany, dramatically. French exports there grew from 2.1 TWh in 2022 to 62.5 TWh in 2024, a 30x increase as Germany's nuclear phase-out created demand for cross-border baseload. Italy remains the single largest buyer throughout, above 50 TWh a year since 2023.

When does France use the most power?

Not when you'd think. The annual demand peak lands at midnight, not the evening. France's heavy reliance on electric storage heating pulls load up during off-peak tariff hours overnight, inverting the early-evening peak you'd see in the UK. A small finding that only shows up once you aggregate three million hourly rows by local time.

How it's built

RTE France API → Python → Snowflake → dbt Cloud → Power BI. A Python job backfills history in 30-day windows and runs daily for new data, loading four raw tables in Snowflake. dbt transforms them into three mart tables that Power BI reads over a live connection.

Extraction

RTE (Réseau de Transport d'Électricité) publishes open APIs for grid data. Four registered applications pull distinct feeds, each with token authentication that refreshes on every run:

  • Actual Generation (417K rows): output by production type at 30-minute resolution
  • Consumption (464K rows): national demand, realised and forecast
  • Cross-Border Flows (1.44M rows): import/export with 8 neighbouring countries
  • Wholesale Prices: day-ahead clearing prices via ENTSO-E

Storage

Data lands in four staging tables in Snowflake (RTE_ENERGY.GENERATION, Azure UK South). The load is idempotent, built on a merge pattern, so a double-fired scheduler updates rows instead of duplicating them.

Transformation

Seven dbt models across two layers. Staging cleans and standardises the raw tables; the mart layer pivots and aggregates into fct_energy_hourly, mart_generation_daily, and mart_cross_border_flows. GitHub-versioned, scheduled daily in dbt Cloud.

Side experiment: agent orchestration

Alongside the main pipeline I set up a small multi-agent workflow in Claude Code, a separate sandbox to learn how agent handoffs and tool permissions behave in practice. Three subagents run in sequence, handing off via shared files:

  • etl-runner fetches a week of hourly RTE data to CSV
  • data-validator checks for nulls, invalid ranges, and missing rows
  • docs-writer turns the validation output into a daily markdown report

On a recent run the validator caught a systematic ETL bug (a blank updated_date on every row) and flagged anomalous coal figures, both written up automatically without manual review.
