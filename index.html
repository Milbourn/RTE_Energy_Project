Mapping France's
Electricity Mix

France generates almost all its electricity from nuclear and renewables, sells the surplus to half of Europe, and saw wholesale prices crash from €281/MWh to €60/MWh in two years. I built a pipeline to track it all: four RTE France APIs feeding 3 million rows through Snowflake, dbt, and into a live Power BI dashboard.

RTE France API access

RTE (Réseau de Transport d'Électricité) publishes open APIs covering real-time and historical grid data. Four separate API applications were registered to pull distinct datasets, each using secure token-based authentication that automatically refreshes credentials on every run.

4.1

What the data shows

The story in this dataset is one of crisis and recovery. In 2022, France took dozens of nuclear reactors offline for emergency maintenance. Generation dropped to 49 GW, wholesale prices spiked to an average of €281/MWh, and the country's role as Europe's electricity powerhouse was temporarily in question. By 2025, nuclear output had recovered to 60 GW, prices had normalized to €63/MWh, and exports to Germany alone had grown from 2 TWh to 62 TWh per year. Does renewable growth actually push prices down?
In normal market conditions, yes. The year-by-year correlation between daily renewables share and day-ahead price settles around r = -0.66 once the 2022 energy crisis passes. During the crisis itself, gas-price shocks dominated everything and the renewables relationship was barely detectable (r = -0.23). This distinction matters: the merit-order effect is real, but it only becomes the primary price driver when the broader energy market is stable.
How did France's exports change after the nuclear recovery?
Exports exploded once reactors came back online. Germany went from receiving 2.1 TWh of French electricity in 2022 to 62.5 TWh in 2024, a 30x increase directly linked to Germany's own nuclear phase-out creating demand for baseload power from across the border. Italy has remained the single largest buyer throughout, at 50+ TWh per year since 2023.
When does France use the most electricity?
The annual average peaks at midnight, not the evening. This is unusual compared to most European countries and is driven by France's heavy reliance on electric heating: overnight storage heaters charge during off-peak tariff hours, keeping demand high through the night. The evening peak visible in countries like the UK (around 17:00-19:00) is much less pronounced here.

Tech Stack Full layer-by-layer breakdown
LayerTool / ServiceRole in this project
Source RTE France Open API Four endpoints covering generation, consumption, cross-border flows, and wholesale prices. Data at 30-min intervals with secure token authentication.
Extraction Python 3.11 Pulls data from the APIs, normalises it, and loads it into Snowflake. Runs automatically each day via Windows Task Scheduler.
Storage Snowflake (Azure UK South) Cloud data warehouse storing all raw and transformed tables. Designed so the daily load can safely rerun without creating duplicates.
Transform dbt Cloud 7 SQL models that clean, reshape, and aggregate the raw data into analysis-ready tables. Connected to GitHub for version control, runs on a daily schedule.
Version control GitHub Full project history for all dbt models, SQL tests, and source definitions.
Visualisation Power BI Desktop + Service Live connection to Snowflake mart tables, 40+ calculated measures, custom HTML KPI cards with sparklines, published as a public Power BI App.
Reflections
What I learned
dbt changes how you think about SQL
I've written SQL transforms for years, but having them version-controlled, testable, and lineage-documented is a different experience entirely. The DAG view makes something that used to be invisible: how data flows through a system, suddenly obvious.
Snowflake is a different class of fast
Coming from Azure SQL, querying three million rows with no indexes in under two seconds was genuinely surprising. The compute/storage separation stops being an abstract concept the first time you scale a warehouse up mid-query and watch the runtime drop.
06
Agent Orchestration with Claude Code A side experiment in multi-agent workflows, separate from the main pipeline

Alongside the main RTE pipeline, I set up a small multi-agent workflow in Claude Code as a training exercise in agent orchestration. Three subagents live in .claude/agents/ in a separate project folder and run in sequence, each handing off to the next via shared files on disk. This was deliberately kept independent of the Snowflake/dbt project, just a sandbox for learning how agent handoffs and tool permissions work in practice.

📥
etl-runner fetches a week of hourly data from the RTE France API and writes it to data/raw.csv
🔍
data-validator reads the CSV and checks for nulls, invalid ranges, and missing rows, flagging issues as pass/fail/advisory
📝
docs-writer takes the validation output and writes a daily markdown report summarising the run and any action items
Sequential handoff via shared files Independent toy pipeline Automated daily QA report

On a recent run the validator caught a systematic bug (a blank updated_date column across every row) and flagged a data quality issue in the raw coal generation figures, both written up automatically in the same report without manual review.
